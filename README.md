# Banking Operations Analytics

## Project Overview

This project analyzes banking transaction data from an operations perspective using SQL, Power BI, and Excel.

The goal is to understand transaction performance, identify exceptions and operational patterns, and generate insights that can support better monitoring and decision-making in banking operations.

## Dataset

- 550,000 banking transactions
- 20 fields
- Transaction data covering 2019–2024
- Includes transaction type, status, amount, channel, account type, KYC status, and other transaction attributes

## Business Questions

The analysis focuses on questions such as:

- What is the overall transaction success and failure rate?
- Which transaction types have higher failure volumes or rates?
- Which channels contribute to transaction failures?
- Where are high-value transactions concentrated?
- Are there patterns across account types or transaction periods?
- Which areas may require deeper operational investigation?

## Tools & Technologies

- SQL — PostgreSQL
- Power BI — Dashboarding and reporting
- Excel — Data exploration and validation
- Power Query — Data preparation
